# FUSE

Mein eigener Minecraft-Launcher.

Hier liegen die Veroeffentlichungen. FUSE holt sich daraus seine Aktualisierungen.

## Einrichten

In FUSE unter Einstellungen, dann Aktualisierung, eintragen:

TNTExplodiert/fuse

Danach auf Nachsehen druecken.

## Was zu einer Veroeffentlichung gehoert

Die ZIP mit dem Programm und die version.json. Aus der version.json liest FUSE die Baunummer. Ohne sie muesste es raten, und geraten wird hier nichts.
