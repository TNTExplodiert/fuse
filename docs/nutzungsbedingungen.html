  6. FUSE für etwas Illegales benutzen. Dazu gehören zum Beispiel Raubkopien, fremde Konten ohne Erlaubnis, Angriffe auf Server und das Verbreiten von Schadsoftware.

5. Deine Welten

FUSE sichert vor dem Spielstart deine Welten, wenn sich etwas geändert hat (Welt-Backups, in den Einstellungen abschaltbar). Klappt eine Sicherung einmal nicht, startet das Spiel trotzdem. Diese Backups liegen im selben Instanzordner (dem Ordner dieser Minecraft-Installation in FUSE) wie die Welten. Bewahre wichtige Welten deshalb zusätzlich an einem anderen Ort auf.

Das gilt auch für Schäden durch Fehler in FUSE, zum Beispiel an deinen Welten.
